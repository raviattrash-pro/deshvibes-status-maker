# DeshVibes Status Maker 🇮🇳

A premium, highly aesthetic React web application designed to help users create gorgeous, animated 25-second WhatsApp statuses for National Days (Independence Day, Republic Day, and other patriotic celebrations).

## Features
* **🖼️ 13 Premium AI-Generated Templates:** Curated photorealistic Indian monuments and flag textures (Red Fort, India Gate, Parliament, Taj Mahal, and more).
* **🌐 Full i18n Support:** Translated UI, badge placeholders, and quotes across 11 Indian languages (Hindi, Bengali, Telugu, Marathi, Tamil, Gujarati, Urdu, Kannada, Odia, Malayalam, and English).
* **🎬 13 Unique Canvas Animations:** Staggered storytelling visuals including rising tricolor balloons, floating oil diyas, crossing airforce fighter jet smoke trails, rotating tricolor sunburst rays, and golden sparkle rain.
* **🎵 Custom Audio & Trimming:** Real-time synthesized patriotic music (brass, ambient, and military march) or support for uploading local audio files with a built-in 25-second start-point trimmer.
* **📥 Silent Video Export:** Uses `canvas.captureStream` and Web Audio track mixing to export high-quality WebM videos with audio included silently in the background—completely avoiding browser screen-recording permission prompts.
* **📱 Mobile-First Responsive Design:** Optimized specifically for mobile viewports with sticky navigation headers and touch-scroll layout configurations.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
